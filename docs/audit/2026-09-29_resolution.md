# Resolving the 2026-09-29 audit

Each finding of [the audit](2026-09-29_audit.md), how it was reproduced, what fixed its cause,
and the test that now fails if the cause returns. A finding is closed only by a reproduction
that failed before the fix and passes after it, and by a check that the test fails when the
fix is removed.

The coder's work space, which the library allocates per coder and which is the larger memory (up to 256 MiB to decode 8 MiB chunks under RS(9,6)), is recorded in the gateway's memory budget; keeping coders between blocks measured 6–10% faster and is the gateway's memory admission to decide. |
| P09 calibration workers and workloads | Thread start and repeated payloads fixed; backend and mixed workloads open | `every_block_written_is_distinct` (`crates/disk/src/measure.rs`) writes 512 transfers of 8 KiB over a 1 MiB span, each block written four times, and finds all 256 of the device's 4 KiB blocks different; writing one payload again and again, as before, fails it. | A job's time runs from when its first worker begins work, after every thread has started, to when its last ends, and its budget from the same start: starting and joining up to 256 threads was inside it. Each write stamps a fresh random word at the head of each of the device's blocks before it is timed, so no block a job writes repeats another and all stay incompressible, where each worker wrote one buffer throughout. Open, as docs/design/measurement.md §8 records: comparing the portable thread-per-transfer path with a platform's asynchronous interface, and measuring mixed reads and durable writes, background work beside the foreground and a device near full, from which the foreground depth and background budgets should follow. |
